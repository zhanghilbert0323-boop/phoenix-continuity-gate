# Phoenix Continuity Gate 0.2.3.dev1 — experimental team-trial preview

This is a prerelease, not production-ready 1.0, a security certification or a
PyPI publication. Existing preview artifacts remain unchanged.

## Included since dev0

- A selected-record workflow example: explicitly `refresh` one command; `status`
  consults its current result without rerunning stored commands.
- Failed and timed-out attempts replace the current selection too. Interrupted
  updates stop with PENDING; there is no fallback to an earlier success.
- Repository binding, record checksums, exclusive-operation locks and atomic
  pointer replacement for a single local workflow. No automatic retry scheduler.
- A bounded resume-cycle experiment and regression tests, plus a bilingual first
  team-trial guide. Internal observations are not customer success evidence.

## Downloads

- `phoenix_continuity_gate-0.2.3.dev1-py3-none-any.whl`: installable package; Python
  3.11+ and Git required, no third-party Python runtime dependencies.
- `phoenix-continuity-gate-0.2.3.dev1.zip`: source, tests, examples, experiments,
  Windows demo launcher and trial guides. Extract the full directory.
- `SHA256SUMS.txt`: consistency checksums, not independent proof of trust.

Start with `TEAM_TRIAL.md` and `DEV_PREVIEW.md` in the ZIP or tagged source.
Installation from a wheel can be offline (`--no-index --no-deps`). Python/Git are
not bundled. macOS remains unverified; Windows and Ubuntu have hosted checks.

Local state is editable and must remain private. Full-repository changes can
invalidate results; ignored files, environment, coverage and authorization of
subsequent operations remain outside scope. Use a separate state directory per
repository/check definition. No telemetry, hosted account or API key is required.

# Phoenix Continuity Gate 1.0.0rc1 — local team-check candidate

Release candidate, **not final paid-team 1.0 readiness**. External acceptance and
commercial value remain unverified. Existing preview artifacts are unchanged.

## Candidate changes

- Owner-approved MIT core, with separately scoped integration/customization and
  time-limited support described in COMMERCIAL.md. No activation or payment gate.
- Tracked TOML configuration with project/check IDs, explicit argv, timeout and
  whole-tracked-repository scope. Unknown settings fail closed.
- Separate check state, definition/command binding, explicit one-check refresh and
  aggregate read-only status; no automatic retry or old-success fallback.
- Same-job GitHub Actions composite action, default status, inputs passed through
  environment variables. Reviewed config still executes arbitrary code on refresh.
- CLI/JSON compatibility, separate-environment upgrade/rollback, recovery guidance
  and a real child-exit/PENDING regression case. No authenticated record claims.

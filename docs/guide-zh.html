先确认运行条件。

02

完整解压下载文件。

下载下方 ZIP，解压到一个新文件夹。打开能同时看到 README.md、START_DEMO.cmd 和 phoenix_continuity_gate 的那一层。不要直接在压缩包里运行文件。

03

启动临时演示。

Windows 用户双击 START_DEMO.cmd：它会检查环境、运行样例，并保留结果窗口。如果使用命令行：在解压文件夹顶部地址栏输入 cmd，按回车，然后运行：

python -B -m phoenix_continuity_gate demo-record

其他系统请在解压文件夹中打开终端，使用已安装的 Python 3.11+ 解释器；命令名可能是 python3。

04

看完四种状态。

程序会在临时样例项目里真正执行测试，结束后清理样例。演示不会替你修改自己的项目。

步骤执行结果记录是否匹配结论
1 · 正常样例通过SUCCEEDEDMATCHPASS
2 · 代码变化后查旧记录SUCCEEDEDCHANGEDBLOCK
3 · 执行新测试，实际失败FAILEDMATCHBLOCK
4 · 修复后重新运行SUCCEEDEDMATCHPASS

两次 BLOCK 都是演示的预期结果。第二步的 SUCCEEDED 属于旧运行，不是新测试；第三步的 MATCH 只表示快照对应，不表示测试通过。

FAQ

卡住时，从这里查起。

窗口闪退，或者没有输出。

从解压文件夹地址栏打开 CMD，执行上面的命令并保留报错。没有输出不能算运行成功。

提示找不到 Python 或 Git。

如果你选择安装，可使用上方官方下载入口，完成后重新打开终端。只检查 Windows 环境可以运行 START_DEMO.cmd --check；这不表示已经执行测试。

提示 No module named phoenix_continuity_gate。

检查命令窗口当前是否在解压后包含 README.md 和 phoenix_continuity_gate 的文件夹里。不要在其他目录运行。

安全软件拦截了文件。

保留提示并反馈这个启动问题，不要为了试用关闭安全防护。

能不能用自己的项目试？

跑通演示后，查看 ZIP 内 README.md 的 record 和 inspect 用法。只使用你有权操作、干净且已有提交的仓库，以及你理解的测试命令；新记录保存在项目外。

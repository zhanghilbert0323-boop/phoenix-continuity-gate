03

启动临时演示。

Windows 用户双击 START_DEMO.cmd：它会检查环境、运行样例，并保留结果窗口。如果使用命令行：在解压文件夹顶部地址栏输入 cmd，按回车，然后运行：

python -B -m phoenix_continuity_gate demo-record

其他系统请在解压文件夹中打开终端，使用已安装的 Python 3.11+ 解释器；命令名可能是 python3。

04

看完四种状态。

程序会在临时样例项目里真正执行测试，结束后清理样例。演示不会替你修改自己的项目。

步骤执行结果记录是否匹配结论
1 · 正常样例通过SUCCEEDEDMATCHPASS
2 · 代码变化后查旧记录SUCCEEDEDCHANGEDBLOCK
3 · 执行新测试，实际失败FAILEDMATCHBLOCK
4 · 修复后重新运行SUCCEEDEDMATCHPASS

两次 BLOCK 都是演示的预期结果。第二步的 SUCCEEDED 属于旧运行，不是新测试；第三步的 MATCH 只表示快照对应，不表示测试通过。

05

可选：接入一个命名检查。

给试用设一个小的时间预算。只用你有权操作的非关键项目，要求 Git 工作区干净、已有提交且没有子模块。遇到安装障碍或无关工作时可以停止，不要为了完成试用删除、暂存或提交它们。

在独立工作文件夹中，将下载的 wheel 安装进新虚拟环境。下方是 Windows CMD 示例，先替换下载路径：

python -m venv .venv
.venv\Scripts\python.exe -m pip install --no-index --no-deps "C:\path\to\phoenix_continuity_gate-1.0.0rc1-py3-none-any.whl"
.venv\Scripts\phoenix-gate.exe --version

版本应为 1.0.0rc1。Linux 使用 python3 -m venv .venv，然后用 .venv/bin/python 和 .venv/bin/phoenix-gate。wheel 安装无需第三方 Python 运行依赖或源码构建。

在目标仓库内审查并跟踪一份 phoenix.toml。下方只是示例，必须替换成项目已有且可信的检查命令。refresh 会以你的权限执行代码，Phoenix 不是沙箱。

config_schema_version = 1
project = "my-project"

[checks.unit]
command = ["{python}", "-B", "-m", "unittest", "discover", "-s", "tests", "-v"]
timeout_seconds = 120
scope = "tracked-repository"

环境未激活时，把 phoenix-gate 换成已安装环境内可执行文件的完整路径。替换项目路径，私有状态必须放在目标仓库外：

phoenix-gate team validate --config "C:\work\my-project\phoenix.toml"
phoenix-gate team refresh --config "C:\work\my-project\phoenix.toml" --state "C:\private\phoenix-rc1" --check unit
phoenix-gate team status --config "C:\work\my-project\phoenix.toml" --state "C:\private\phoenix-rc1"

refresh 明确运行一个检查，status 不运行测试。正常改动后，状态查询可能拦截旧证据；先判断是否需要新检查，再明确刷新，不要加入自动循环重试。改检查定义不能继承旧成功结果；缺失或失败的检查会阻止聚合状态通过。

整仓库变化（包括文档）都可能使记录过时；环境和忽略文件不在范围内，本地 JSON 可编辑。遇到 PENDING 或锁错误时停止，按 ZIP 中 docs-dev/TEAM_CONFIGURATION.md 排查。确认原操作及子命令都已停止，才考虑手动恢复锁。

同 job CI 接入见 ZIP 中 docs-dev/GITHUB_ACTIONS.md 及工作流示例；不承诺跨机器或跨 job 复用凭证。固定 ZIP 通过 91 项内部 Windows 测试，四组云端环境也实际运行了适配器；这些不是客户验收结果。

MIT 核心免费。接入、定制和限期支持另行约定，不因试用而要求购买，也不默认承诺 SLA。

FAQ

卡住时，从这里查起。

窗口闪退，或者没有输出。

从解压文件夹地址栏打开 CMD，执行上面的命令并保留报错。没有输出不能算运行成功。

提示找不到 Python 或 Git。

如果你选择安装，可使用上方官方下载入口，完成后重新打开终端。只检查 Windows 环境可以运行 START_DEMO.cmd --check；这不表示已经执行测试。

提示找不到模块，或 phoenix-gate 不存在。

源码演示要在包含模块的解压目录运行；安装后的检查请使用虚拟环境内 Python/phoenix-gate 的完整路径。在一个环境安装，不等于其他解释器也已安装。

安全软件拦截了文件。

保留提示并反馈这个启动问题，不要为了试用关闭安全防护。

Phoenix 把命令执行结果与当时的 Git 状态、跟踪文件快照关联起来。上下文变化时，它会解释旧记录为什么不再匹配。

−

保留必要的不确定性。

  • 不证明测试充分性或代码正确性
  • 不自动重试、不分析依赖，也不建议跳过测试
  • 不核验被忽略的文件或环境变化
  • 本地记录可编辑，不提供跨机器或跨 job 凭证

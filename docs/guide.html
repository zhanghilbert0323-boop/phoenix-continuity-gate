03

Start the disposable demo.

On Windows, double-click START_DEMO.cmd. It checks installed prerequisites, runs the sample and keeps the window open. For a terminal: open the extracted folder, enter cmd in the File Explorer address bar and press Enter. Then run:

python -B -m phoenix_continuity_gate demo-record

On other systems, open a terminal in the extracted folder. Use your installed Python 3.11+ executable; its name may be python3.

04

Read all four moments.

The program runs real tests in a temporary sample project. It cleans up that sample afterward; the demo does not edit your own project.

StepExecutionFreshnessGate
1 · Working sampleSUCCEEDEDMATCHPASS
2 · Inspect old record after changeSUCCEEDEDCHANGEDBLOCK
3 · Run new test; it failsFAILEDMATCHBLOCK
4 · Repair and run againSUCCEEDEDMATCHPASS

Both BLOCKs are expected. Step 2 describes an old successful run, not a new failing test. MATCH in step 3 describes the snapshot, not success.

05

Optional: try one named team check.

Set a small time budget. Use only a non-critical project you own or are authorized to test, with a clean committed Git tree and no submodules. Stop on setup obstacles or unrelated work; do not delete, stash or commit it just to finish a trial.

Install the downloaded wheel in a fresh virtual environment. Windows CMD example, from a separate working folder; replace the download path:

python -m venv .venv
.venv\Scripts\python.exe -m pip install --no-index --no-deps "C:\path\to\phoenix_continuity_gate-1.0.0rc1-py3-none-any.whl"
.venv\Scripts\phoenix-gate.exe --version

The version must be 1.0.0rc1. On Linux use python3 -m venv .venv, then .venv/bin/python and .venv/bin/phoenix-gate. Wheel installation needs no third-party Python runtime dependencies or source build.

Review and track a phoenix.toml in the target project. This example must be adapted to its existing trusted test command. Refresh executes that code with your permissions; Phoenix is not a sandbox.

config_schema_version = 1
project = "my-project"

[checks.unit]
command = ["{python}", "-B", "-m", "unittest", "discover", "-s", "tests", "-v"]
timeout_seconds = 120
scope = "tracked-repository"

Use the installed executable’s full path if the environment is not activated. Replace project paths; private state must be outside the target repository:

phoenix-gate team validate --config "C:\work\my-project\phoenix.toml"
phoenix-gate team refresh --config "C:\work\my-project\phoenix.toml" --state "C:\private\phoenix-rc1" --check unit
phoenix-gate team status --config "C:\work\my-project\phoenix.toml" --state "C:\private\phoenix-rc1"

Refresh explicitly runs one check. Status runs no test. After a normal edit, status may block stale evidence; review whether another explicit refresh is appropriate. Never add an automatic retry loop. Changed check definitions cannot inherit old successes; failed or missing checks block aggregate status.

Whole-repository changes, including docs, can stale records. Environment and ignored files remain outside scope; local JSON is editable. On PENDING or a lock error, stop and follow docs-dev/TEAM_CONFIGURATION.md in the ZIP. Confirm the owner and child commands have stopped before manual lock recovery.

For same-job CI use docs-dev/GITHUB_ACTIONS.md and its workflow example in the ZIP. Cross-machine or cross-job receipt reuse is not supported. The fixed ZIP passed 91 internal Windows tests and four hosted matrix jobs exercised the adapter; those are not customer acceptance results.

The MIT core is free to use. Integration, customization and time-limited support require a separate scope; no purchase or SLA is implied.

FAQ

If something gets in the way.

The window closes, or I see no output.

Open Command Prompt from the extracted folder and use the command above. Keep the error text. No output does not establish success.

Python or Git is missing.

Use the official download pages above if you choose to install them, then open a new terminal. To check only the Windows environment, run START_DEMO.cmd --check. That check does not execute tests.

No module named phoenix_continuity_gate, or phoenix-gate not found.

For the source demo, use the extracted folder containing the package. For installed checks, use the virtual environment’s full Python/phoenix-gate path. Installing into one environment does not install into another.

My security software blocks a file.

Keep the message and report the startup obstacle. Do not disable security protections to complete the trial.

Can I use it on a real project?

Use the optional team trial on an authorized non-critical project. Keep state private and outside the repository. Do not upload credentials or raw records.

I need the previous preview.

The historical v0.2.2 ZIP is preserved. It does not include the candidate’s named-check interface; report your actual version.

This guide sends no feedback or project data. Copying text only uses your browser clipboard. Review anything you share; do not attach private code, credentials, customer information or complete execution JSON.
